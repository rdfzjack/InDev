# 《正在开发中》设计方案

> 一个做坏了的 CRPG。

---

## 一、定位

- **一句话**：底子是一个很基础的回合制 CRPG，但所有东西都有点不对。玩家收集队友、应付 bug、寻找一个可能还没开发出来的结局。
- **参照**：做坏了的《博德之门 3》。形式必须是正统 CRPG——旁白、队友 banter、检定、营地对话、结局幻灯片——先做对，才谈得上坏。
- **体量**：两小时。4 个角色，2 个任务，1 个村庄，1 个魔王。DnD 3 级团，传统 d20。
- **名字**：《正在开发中》。版本号永远停在 0.9x，正式发售也不改。

### 核心原则

1. **信息给足，框架不给**。永远给出事实，永远不给可以站的位置。
2. **发生的事不被处理**。世界不为任何选择重新组织自己，没有道德系统，没有后果反馈。
3. **角色是本地居民，不是被困的角色**。他们能看见故障，不能解释，也不干预。不质问开发者，不要求逃出去，不对玩家说话。
4. **不解释，不辩解，不在任何渠道回应**。发售后有人问"这个设定的意义是什么"，正确答案是没有意义，但这句话不说。
5. **bug 不能太多**。笑点依赖对照。周围越正常，这一处越好笑。
6. **它一点都不巧妙**。玩家一次都不会觉得自己聪明。不巧妙 ≠ 不用心——所有手艺都用在让人笑，不是让人佩服。

## 二、美术

- **PS2 风格 low poly**，写实比例，手绘质感贴图。不是现在流行的风格化。
- **明亮饱和**，偏 BG3 而非 BG1/2。光照烘进贴图，unlit 为主。
- **写实比例很关键**——Q 版的话穿模会被当成风格，写实的人穿过墙才是穿模。
- **完成度要高，但明确分区**：主线场景精致，支线/边缘区域是白模区或 AI 资产占位区。两种质量并存，只可能是选择，不可能是能力问题。
- **玩家越好奇，看到的白模越多**。老实走主线的人几乎看不到。

### 技术要点（UE5）

**关掉**：Lumen、Nanite、TSR/TAA、Motion Blur、Bloom、Auto Exposure、AO、Lens Flare、Vignette、色差、Film Grain。材质全部 Unlit。

**自己做**：顶点抖动（clip space 坐标量化）、affine UV（无透视矫正贴图）。

**决定像不像的其实是资产**：贴图 64×64 / 128×128，关 mipmap，Filter 设 Nearest，内部渲染 320×240 或 512×384 再拉伸，15-bit 色深 + 一点 ordered dithering，阴影用贴片。

**不要全套精确复刻**。挑三四个坚决执行，剩下允许它是现代的——全套复刻反而会做出一种很干净的、有意识的复古感。

## 三、四个角色

| 角色 | 职业/种族 | 故障 | 来源 |
|---|---|---|---|
| 主角 | 人类圣骑士 | 武器绑定位置不对 | 尸体 |
| 你老公 | 卓尔重甲法师，队长 | 经常点不动 | 暗夜精灵王子 |
| 诗人 | 人类吟游诗人 | 掉出地图，只显示名字 | 低低 |
| SL | 提夫林盗贼 | LOD2 贴图错误 | 小扬 |

**这四个覆盖了四种交互层**：视觉、交互、存在、元层。第一个 dungeon 把它们全部演示完，之后只复用。

### 主角

- 岁月静好（不太活）。
- 开场让你选性别、选职业，建卡界面做得很认真，进游戏发现变成了默认圣骑士。中间没有任何暗示，进去之后也不宣布。
- 对话选项里永远挂着三个：**我不知道 / 我没意见 / 哈哈哈**。语气要平，不带感叹号。混在正常选项中间，不特殊标注。
- 武器绑在不存在的骨骼上。他自己的视角一切正常，是别人一直在问"你的武器呢圣骑士"。换武器不解决问题。
- 战斗里可以选择 **【躺着】**。图标认真做，描述只有一句"你躺着"。冷却一回合，AC +2。
- 誓言那一栏是空的。他不可能破誓，因为不知道誓言是什么。
- 是老公的第八个配偶。他不知道这回事。

### 你老公

- 名牌上写着「你老公」。不是名字，是关系字段显示成了名字。对话框的说话人也是这三个字，从头到尾没出现过别的称呼。
- 全队最强。AC 巨大，能丢火球（3 级法师本来没有火球，数值没改）。另外三个真的可以躺着。
- **他的技能栏里没有「躺着」**。不是灰的，是根本没有。
- 队长，会定期约谈队员。"饭后我要和你谈话。" → 点不动 → 第二天："你妄图蒙混过关。" → 措辞一次比一次正式 → "我对你很失望。" → 你可以选"哈哈哈"。
- 初遇时走完整套招募流程，而他从一开始就是你老公。入队提示："你老公 加入了队伍。"
- 问他"你真的是我老公吗"，他说"问这个干嘛小笨蛋"。这是全游戏他唯一一次不严肃。
- 问"我是你第八个配偶？"，他说"你就是"。
- 从来不问主角的武器去哪了。所有人都问过，只有他没问过。
- 长发黑皮。

### 诗人

- 入队过场动画中直接掉下去：关掉碰撞，让重力把他拽下去，台词照常播完，镜头忠实跟随。另外三个人：「……」
- 掉下去期间模型不在，只有名字牌浮在他实际坐标上（在地下很远处）。对话、战斗、回合全部正常。
- **每次场景切换（关卡加载）他都会回来**。没人教过玩家这件事。
- 他的碰撞体还在跟随，所以陷阱还是会被触发。你只看见一个名字飘过去，然后陷阱响了。他会"哎哟"。
- 他对下面的描述毫无信息量："下面挺安静的。""没什么。"
- 结算幻灯片里他那条没有立绘，只有一个名字。
- （DLC 设定：他本来就是亡灵。正片不点破，和故障无因果关系。）

### SL

- 远看是红色提夫林，走近是蓝色的——LOD2 烘焙时把牙齿贴图糊到了整张脸上。
- **他不承认**。你说他贴图不对，他说"哪有现在不是对的吗"。他说的是对的，因为他永远处在被看清楚的位置上。你没法给他看，没有截图功能，唯一的证据是你自己的眼睛。
- 主角会说："我以为你是红色的提夫林，没想到你是蓝色的提夫林。"——这是主角全程少数几次主动开口。
- 一直劝你 save and load。对所有类型的故障都有反应，内容永远是"读个档试试"。偶尔真的管用，所以他更有底气。
- 他的招是 **【读取存档】**：战斗回到开始时的状态。没有缺陷，没有代价，就是纯粹的 SL。描述只有一句。
- **他分不清技能层面的 SL 和玩家层面的 SL**。战斗外也会建议你退到主菜单读档。
- 他的名言：**"有人走路外八，有人说话大声，有人总是迟到。没人因为这个不跟他玩。"**
- 解除陷阱是他的专业，而那个功能没做。"我应该能解的。"

## 四、旁白

CRPG 旁白是现成的全知视角，玩家早就接受了它的存在。**它说话的腔调是老式 CRPG 的庄严文学腔，内容是引擎日志。**

```
你推开门。石阶向下延伸，消失在黑暗中。这段区域的光照尚未烘焙。

他看着你，眼中有某种你无法读懂的东西。他的面部混合形状没有被正确导入。

你伸手去触碰他。碰撞体不在那里。

那只小怪占用了当前可用的全部显存。你们身上所有的贴图都模糊了。你依然认得他们。

该任务引用的字符串键值未能解析。原始数据不可访问。

摄像机的上方向向量计算失败。世界没有翻转。

他的物理体在切换 ragdoll 的瞬间继承了动画的末帧速度。他正在以每秒四十米的速度垂直上升。

你躺着。这是允许的。

你已倒下。你正在跟随队伍。

该标记不应在此阶段显示。
```

### 规则

- 旁白和角色**不在同一层面**。角色听不见旁白，旁白不为角色服务。两边说的是同一件事，但都不知道该怎么办。
- 旁白是这游戏唯一诚实的东西。它从不撒谎，它只是不管用——它准确地告诉你一切，而这些信息毫无帮助。
- **它只报告它看得懂的**。GBuffer、VT 这类玩家认不出来的故障，旁白也不说。
- **例外**：少数几次检定，旁白的评语和实际结果相反。你没过，它夸你干得漂亮。只发生几次，所以你永远不知道这次的评语算不算数。

## 五、队友吐槽系统（模块化）

必须做成系统，不能一条条手摆。

```
BugEvent {
  Type        // 穿模 / 交互失效 / 数值异常 / 位置异常 / 文本缺失
  Instigator  // 谁身上出的（可为空）
  Location
  Severity    // 影响玩法 / 只是好笑
}
```

每个队友订阅广播，各有一张**反应表**（用 DataTable，不要写死在蓝图里）：

- **SL** → 对所有 Type 都有反应，内容永远是读档
- **老公** → 只对**你的**行为有反应（躺着、蒙混过关），不评论别人的故障
- **诗人** → 只对自己的有反应，无所谓的语气
- **主角** → 永远是那三个选项

**必要的控制**：冷却、优先级、已说过标记、**沉默权重**（有一定概率谁都不说——"三个点"就是这么来的）。

旁白订阅同一个广播，但总是先于队友。**旁白报告，队友评论。**

### 行话

角色知道自己在一个游戏里（路线 A），但这个知识不带来任何行动。他们用日常语气聊引擎。

```
"你刚才穿模了。"  "嗯。"（继续走）

"你去哪了？"  "地图外面。"  "哦。"

"他这两天点不动。"  "碰模了吧，过几天就好。"

"我今天动作有点飘。"  "帧数低吧。"

"别往那边走，那边还没做完。"  "什么时候能做完？"  "不知道，一直这样。"
```

说得很自然，没有引号，没有停顿，不是在玩梗。**"地图外面"是个地名，不是状态。**

## 六、地图与结构

用**传统关卡切换**，不要无缝——加载画面是笑点，而且诗人靠场景切换回来。

| 区域 | 内容 |
|---|---|
| 营地 | 很小。营地对话、老公约谈。全程回来三四次。 |
| 村庄 | 枢纽，笑点密度最高。一条主街，酒馆/商店/村长家/神殿，一个广场。走一圈两分钟。 |
| Dungeon 1 | 三五个房间。几乎全是好的，笑点都在队友身上。 |
| Dungeon 2 | 三五个房间。环境和系统开始坏。 |
| 白模区 | 从村庄外围某条路进去，没有引导。龙在里面。 |
| 魔王门 | 离村庄很近，早期一定会路过。地图上一直标着。 |
| 通往魔王的路 | 会翻转的斜坡。尸体一路悬空。 |

**密度比面积重要**。全部加起来一小时能走遍。每个区域给一个"没做完"的边缘，两三处就够。

### 加载画面

永远只有一条提示：

> **你知道吗？圣骑士可以使用重甲。**

它完全正确。5e 里圣骑士确实精通重甲。它毫无用处，而且你会看几十遍。到魔王战之前那一次，还是这一条。

## 七、村庄

### 商店（只做一家）

- **商品列表第三格是空的，点了会卡死**。必须是真的无响应，只能 alt+F4。重进之后没有任何补偿，队友说："**不是说了别点吗。**"
- 事前有人提醒过"别点第三格"。所以这是你自己的错。
- 老板永远不修。你告诉他，他说"哦"。
- 库存永远不刷新。
- 有一件商品图标是粉红方块，名字叫 `Item_01`，老板极力推荐。
- 有件道具名字是"炸弹"，图标是面包，描述是第三种东西，实际效果是第四种。只有一个，用掉就验证不了。

### 其他

- **被害村民**：自动触发 level sequence，**只有他的跳过是坏的**（按下去有反应，进度圈转到一半停住；提示文字"按住 空格 跳过"一直在屏幕角落）。玩家必须研究他的触发半径，绕路走。任务交完之后还在触发。
- **铁匠**：碰撞体太大，对话要喊（对话框文字变大），任务道具只能扔给你，在地上滚。有时候滚进缝里就拿不到了。
- **酒馆门**：关掉 RVO avoidance，四个人进门打转七八秒。做成**地点属性**不是角色属性，用触发盒临时改参数。诗人掉下去的时候进门就顺畅多了。
- **村庄 BGM 是 boss 战音乐**。全村人该干嘛干嘛。旁白只说一句："音乐轨道索引错误。"
- 有只鸡卡在墙里，只有头露出来，还在正常地叫。全村人习惯了。
- 大汉 NPC 配的是少女音，或者语音是对的而字幕在谈恋爱（只发生一次，没人反应，不重复）。
- 女王（或某个正经 NPC）文本全是错别字——同音字形近字，校对失败的那种。她越庄严越好。语音是对的，只有字幕错。
- 有个 NPC 叫 `NPC_Villager_04`，大家就这么叫他，他对这个名字没有意见。

## 八、Dungeon

三五个房间，一两场战斗。每个房间只负责一件事。

### Dungeon 1（笑点全在队友身上，环境干净）

- 诗人入队过场掉下去，之后场景切换回来——玩家在这里第一次发现规律
- 第一场战斗里玩家发现技能栏有「躺着」
- 老公约谈 → 点不动（放在结束后的营地）
- 开锁、被动察觉、谜题机关全部正常运行一遍，建立基准
- **谜题的提示文本就是答案**（从 Dungeon 2 提前到这里）：石碑上写着"依次拉下右边、中间、左边的拉杆"。旁白："该谜题的提示文本尚未替换。"老公："那就拉吧。"
- **解除陷阱功能没做**：点了提示"该功能尚未实现"。只能绕。诗人的名字还是会踩。玩家被迫大量 SL。

### Dungeon 2（环境和系统开始坏）

- **战斗触发范围比房间大**：你还在走廊就进战斗，敌人在下一个房间，第一轮谁都够不着谁
- **宝箱**：打开动画播了但没开，能再开一次；或者战利品掉在箱子里面够不着（旁白会告诉你里面有什么）
- **可无限装备的传说装备**：装上之后背包里还有一个，**全队共享同一个实例**，属性全生效。**卖掉之后四个人同时掉光**（引用计数的正常行为）。想买回来——**它在第三格。**
- **Dungeon boss 死后尸体飞进墙里**。能看见，交互点在墙另一边。旁白准确告诉你里面有什么。读档重打还是往同一个方向飞。**换个位置打有用**——玩家靠对 bug 的理解解决问题。
- 检定异常：DC 是负的（必然成功，还是要你掷）、DC 45（3 级团永远过不去）、`DC {难度}`、说服检定用力量作为调整值

### 其他可用的

火把光源在火把外面半米、某个房间没烘焙全黑、回头路和来时不一样、楼梯没碰撞滑下去上不来、敌人卡在生成点、敌人死了但回合还轮到他（全队等他行动，等一会儿，跳过）

## 九、白模区与龙

- 从村庄外围某条路进去，**没有任何引导**。
- 一片白模，没有杂兵，没有宝箱，没有 NPC。**只有一条龙。**
- 龙做得极其认真：模型、动作、多阶段、专属音乐。**这首歌如果玩家没找到这里就没人听过。**
- 可打可对话。不打它也不会攻击你——你可以走近，绕着它转，看很久。**它是全游戏最好看的东西，站在最空的地方。**
- 打完什么都不给。结算不统计它。
- 队友："这边还没做。"然后就开打了。
- 打完龙倒在白模上，**然后它开始平移**。

## 十、魔王

- **地图上从游戏一开始就标着他的位置**。没有任何人提过。图标一直在闪，像个未读提示。
- 你早期一定会路过。走到门口，门锁着，提示是 `LockedDoorPrompt_Default`。**那时候你甚至不知道要打魔王。**
- 隔着门能听见音乐——那首店铺 BGM。它一直在那儿放着。
- 第二次来门开了。没有解释，没有钥匙。
- 魔王认真做：登场演出、台词、多阶段、庄严的音乐。
- **第二阶段开始时音乐切成店铺 BGM**。循环三十秒一轮，打五分钟转十圈。不中途修好，一直放到结算。
- 队友："我都被它洗脑了。""第几遍了？""第十一遍。"打到后面有人开始哼。
- **魔王自己上天**：ragdoll 继承动画末帧速度，有加速过程，带旋转，越飘越快，飘出画面。战斗音乐还在放，放到循环点又从头来一遍。
- 队友：**"嘿快看，boss 上天了。这个是不是代表我们胜利了？"**
- 旁白：无法判定。
- 可以重打，每次出的问题不一样（卡在地里 / 血量不掉 / 直接不出现）。某一次之后游戏就往下走了，不解释为什么这次算数。

## 十一、结算

**从结局幻灯片开始，游戏就不再坏了。** 不解释为什么，它就是好了。干净、完整、一个 bug 没有。

### 结构

四个人各一段 + 全队结局。线性主线，**这是唯一的分支叙事**，其他都是做坏的。

### 隐藏统计（不影响好感度，但会统计）

好感度是坏的、会乱的、和行为脱钩的（某天一觉醒来全乱了，不能改回去，数值乱了但人没变）。而在它下面，有个东西一直在数你到底做了什么。

```
你点了他 412 次。
你躺了 66 次。
你说了 87 次"我不知道"。
你说了 112 次"哈哈哈"。
你点了第三格 2 次。
读档次数：0
你在角色创建界面停留了 14 分 22 秒。
```

格式像调试信息。一个字的情绪都不带。

**这些统计的不是选择，是习惯。** 无法被优化，也无法被攻略。它是你玩这个游戏的方式，不是你在这个游戏里做的决定。

### 关键几条

- **主角那一行**：他点老公的 412 次里，大部分发生在约谈那天晚上。
- **读档次数 0**：SL 队友会说"你绝对删存档了，哪有人玩 crpg 不 sl 可恶！"他不信统计。如果 SL 很多次，他会很欣慰："你学会了。"
- **老公那条不受任何输入影响**。不管你做了什么，他那栏还是「你老公」。这是这个游戏里唯一一个不变的东西，而游戏一次都没强调过。
- **"你找到了你的真爱。"** 镜头切到你老公。这段必须做得非常真诚——立绘精致，音乐好听，文本写得动人，一个字的自嘲都不能有。而你什么都没做，整个游戏甚至没有点成功他。
- 制作人员名单完全正常运行。

## 十二、元层

### 规则

角色知道自己在游戏里，**但这个知识不带来任何行动**。不反抗，不求救，不质问。他们只是知道，然后照常过日子。他们对自己的毛病有态度，但从没人问过为什么会有故障。

### 可解包内容

老公那段一直点不动的约谈对话，**真的写在包里**。放在正常目录，正常命名，不加密。没有开发者留言，没有"恭喜你找到了"。

内容是：

> "你下次能不能不要躺着？"
> "哈哈好。"

玩家挖了半天，就这个。而他为此升级了三次措辞。

### 自己坏掉的东西

- 存档界面显示的游玩时间是负的（每次开游戏看见一眼，到结算时数字更负了）
- 设置菜单里有一项是灰的，写着"暂未开放"——**唯一一个用了正常措辞的地方**
- 地图上有个问号图标点不了
- 任务日志里有一条你没做过的已完成任务
- 成就/图鉴里有几格永远解锁不了
- 过场里角色穿的是默认装备
- 有一段过场没有音频，大家在无声地说话，只有字幕

### 不做的

- 不做假 bug（故意闪烁、乱码、破损效果那一套）
- 不兑现（永远没有"其实这是设定"的揭晓）
- 不在 patch note / 采访 / 任何渠道说明
- 不装神秘（正常发补丁修真的 bug，别的什么都不说）

## 十三、宣传

### 预告片（三个镜头）

用 CRPG 预告片那套正经运镜：缓慢推近、景深、庄严配乐。画面越像正经预告片，内容越荒谬。

1. **你老公**站在那儿，镜头推近，头顶名牌清清楚楚写着「你老公」。停两秒。
2. **一个空场景，只有一个名字浮在半空**。镜头以完全相同的运镜推近那个名字。
3. **SL** 看着你，认真地说："读个档试试。"

黑屏，标题：**《正在开发中》**

（可选：标题出来之后画面没切干净，或者音乐没放完就断了。）

### 标语

> 我以为你是红色的提夫林，没想到你是蓝色的提夫林。

### 已知代价

- 搜索会是灾难（英文名慎重，直译太容易被认成占位符）
- Steam 审核可能会以为标题没填完
- 会有人真的认为开发者不会做游戏，给差评——**这是要付的代价，不是能规避的**
- 没法在商店页写"本作包含 BL 要素"然后不提供攻略路线

### 美术是唯一的信任凭证

画面好，别人才会认为 bug 是故意的。**可以砍战斗、砍体量、砍职业，美术水准一旦掉下去，整个笑话的前提就没了。** demo 对外那一版不能用占位资产。

## 十四、开发

### 排期

一个月能做出扎实的 **20–30 分钟 demo**：建卡骗局、你老公那段、第三格、一个坏任务、魔王上天。完整两小时大概三个月，主要卡在文本和调试。

### 先后

1. **旁白文本最先写**。它是这个游戏的声音，写完之后所有别的东西都有基准，而且不需要引擎里有东西。
2. 拿 RPG 回合制模板改。占位阶段直接用几何体 + 名字牌，先把时机跑通。
3. 故障清单做成表格：每一条故障、触发条件、持续时长、恢复方式。**那份表格大概是这个游戏唯一一个完全严谨的东西。**

### 技术备忘

- 诗人：关碰撞 + 重力拽下去。**Kill Z 要关**，落速要限，到某个 Z 停住（要的是"他在下面"，不是"无限下坠"）。名牌不跟着掉，留在他原来站着的位置头顶。跟随逻辑要停。
- 进门挤：关 `bUseRVOAvoidance`，保留胶囊体碰撞，目标点相同。要"转圈"而不是卡死，就把 `AvoidanceConsiderationRadius` 调大，让他们过度避让。**做成触发盒，只在特定门口生效。**
- 魔王上天：给 ragdoll 向上 impulse + 随机角速度，关重力或调低 damping。
- 尸体悬空：死亡那一帧停掉 simulation。**物理同一个系统坏在两个方向上**——一个冻住了，一个失控了。
- 尸体平移：敌人身上原来的位移逻辑没关，保持死亡姿势沿 NavMesh 走向生前的目标点。**可以一路跟着你。**
- SL 统计：**用独立于存档的持久化文件**（meta slot 或 config），不然数字会跟着回档。玩家能找到并删掉，不防。
- 异常退出检测：退出时写标记，启动时读，读到了就在下一次对话触发"不是说了别点吗"，然后清掉。
- 对话插件候选：Not Yet Dialogue System / Narrative Pro / Ink / Yarn Spinner。Cinematic 部分靠 Sequencer，两边事件挂钩。**"跳过是坏的"直接不接那一段的跳过逻辑即可。**

### 一个人还是团队

- **不能外包**：故障清单、全部文本（尤其旁白）、触发时机和节奏、那三个选项的出现位置。
- **可以外包**：建模绑定贴图、音乐音效（尤其那首要洗脑的短循环）、战斗系统搭建、本地化。
- 真实的沟通成本：**这个项目非常难向别人描述**，每个新人都要重新解释一遍"这个 bug 是故意的"。
- 建议先自己做完 20 分钟 demo，做完才知道卡在哪、需要什么人。

---

## 十五、不要做的事

- 不要给它意义。不要有"其实旅程本身就是结局"之类的收束。
- 不要让角色为任何事辩解。不要有 NPC 表示接受或不接受那段关系。
- 不要在宣传语里提 BL。让它保持在"这个人叫什么名字"那个级别。
- 不要自嘲式地打破第四面墙。角色承认 bug 的语气是承认天气，不是"哈哈这游戏做得真烂"。
- 不要让"疑似 bug"兑现成揭晓。玩家一直不确定，直到通关都不确定，去论坛问也没人能确定。
- 不要让 bug 多到成为常态。笑点依赖对照。
- 不要做玩家看不出来的故障（GBuffer、VT 之类）。做了等于没做。

来自十年前的《有一半人日常阵亡的恶人团》。

主角从黑暗阵营最帅的那个，变成光明阵营最该负责的那个，而他还是一样不太活。
